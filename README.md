This repository contains interactive Jupyter notebooks for a complete Data Science course. Each lesson is designed to be run directly in your browser with no installation required.

## 💻 How to Use These Notebooks

### Option 1: MyBinder (Recommended - No Installation)
1. Click any lesson link above
2. Wait for the environment to load (~2-3 minutes)
3. Execute cells with `Shift + Enter`
4. Experiment with the code!

### Option 2: Local Installation
```bash
# Clone repository
git clone https://github.com/AICE2024/data-science-course.git

# Install requirements
pip install -r requirements.txt
# Launch Jupyter
jupyter notebook
